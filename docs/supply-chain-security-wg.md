# Supply Chain Security Working Group

The Supply Chain Security Working Group brings together everyone running Rust in production to share how they build software securely. The group provides a place to coordinate work on mirroring crates.io, managing build tools, reviewing and applying policies to new crate releases, and responding to malicious crates and other supply-chain attacks.

## Status

The working group held its kickoff meeting on September 22, 2026, and has scheduled its next meeting for October 27, 2026. Discussion is ongoing in the [commercial-network channel on Zulip][zulip-thread]. We are looking for participants to help prioritize the first deliverables.

## Goals

* **Identify and prioritize ecosystem gaps** across registry mirroring, publishing, vetting, and vulnerability response.
* **Document requirements for registries and mirrors**, including the web APIs and lifecycle changes that downstream tooling must observe.
* **Provide feedback and case studies** for work on crates.io, Cargo, dependency cooldowns, trusted publishing, and advisory monitoring.
* **Coordinate upstream contributions and funding** with existing maintainers and Rust Project teams.
